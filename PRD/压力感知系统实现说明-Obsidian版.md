# 压力感知系统实现说明

## 主干链路

- 全局约定
	- 顺序严格
	- 一份标准帧
		- 广播与入库同一个对象引用
		- 不存在两份
	- 唯一换算入口
		- pressureFrameProcessor
		- 前端不算第二遍

- 阶段顺序
	- 一 连接设备
	- 二 帧解析
	- 三 标准矩阵
	- 四 压强压力换算
	- 五 分发与入库

- 扇出分支
	- 实时渲染
	- 采集入库
	- 历史回放
		- 复用实时渲染组件
	- 数据对比
	- COP 报告
	- 导出导入

## 三 标准矩阵

- 在线判定
	- 端口未打开
		- 离线
	- 类型为空
		- 跳过该端口
		- 避免无效键
	- 距上帧超一秒
		- 离线

- 规格校验
	- 宽乘高不等于点数
		- 置矩阵错误
		- 质量置设备异常
		- 附期望尺寸与实际长度
		- 直接返回不写业务字段
	- 通过则拷贝业务字段
	- 输出键为设备类型
		- 不再是端口路径

- 朝向归一
	- 取朝向配置
		- 优先按键取
		- 回退全局
	- 三步顺序固定
		- 旋转
			- 顺时针旋转角度除以 90 次
			- 每次交换当前宽高
		- 左右
			- 左值为假则水平翻转
		- 上下
			- 上值为假则垂直翻转
	- 默认值
		- 靠背 不左翻 上正 零度
		- 坐垫 左正 上正 二百七十度
	- 旋转九十或二百七十度
		- 宽高互换
		- 重算并写回规格元数据
	- 写回本帧实际朝向
		- 供前端判断是否补转

- 持久化与迁移
	- 配置存方向文件
	- 启动时加载
	- 兼容迁移
		- 坐垫为未翻转加旋转
			- 重置为标准坐垫朝向
		- 靠背为全默认
			- 重置为标准靠背朝向
	- 任意角度归一到四个方位

## 四 压强压力换算

- 单帧处理链
	- 一 线序还原
	- 二 矩阵插值
	- 三 朝向归一
	- 四 预压力置零
	- 五 有限值与非负归一化
	- 六 按标定文件规则补齐完整压强矩阵
	- 七 压力换算

- 处理参数来源
	- 采集中且有快照
		- 用采集快照
	- 否则
		- 用当前配置
	- 范围钳制
		- 阈值零到四千零九十五
		- 高斯零到四
		- 相干一到十
	- 当前语义
		- 只为旧接口 配置文件和历史采集快照兼容
		- 不改变标准 ADC 压强 压力 点数或面积

- 预压力置零
	- 用途
		- 座椅自重产生恒定底值
		- 织物预紧产生恒定底值
		- 测量前减掉
	- 存
		- 前端取当前帧原始 ADC
		- 提交给后端
		- 后端记基线与置零时间
	- 找
		- 先按完整键查
		- 未命中按短键查
			- 短键为键名末段
		- 都没有则不置零
	- 用
		- 长度校验
			- 基线长度不等于点数
			- 整个置零跳过
		- 逐点取当前值减基线
		- 结果不小于零
	- 位置
		- 在标定之前
		- 置零结果不再经过 ADC 阈值或空间高斯
		- 后续统计都基于净压力
	- 设计意图
		- 短键兜底便于跨系统复用基线
		- 长度校验防止切换系统后错位相减

- 阈值与高斯兼容状态
	- filter gauss coherent 字段继续保留
		- 兼容已有界面 接口 配置文件和历史记录
	- 标准帧处理明确不应用
		- filterApplied 为 false
		- gaussianApplied 为 false
		- gaussianSigma 为零
		- temporal 为 false
	- 置零后的 ADC 只做两项安全归一化
		- 非有限值归零
		- 负值归零
	- 高斯工具函数仍保留给旧调用
		- 当前标准帧链路不调用

- 矩阵拓扑与压强边界
	- endi 靠背的无传感器填充位
		- 由线序映射与插值阶段输出零
		- 属于设备点位拓扑
	- 标准压强处理器
		- 不再按矩阵位置追加有效区掩码
		- 不再清除标定文件已经输出的压强点

- 压强标定
	- 当前公式
		- 文件 point_pressure_calibration.js
		- 座椅 V2.7.46
		- 靠背 V2.7.52
	- 标定接口
		- calculateBasePressure
		- getCalibrationInput
		- calculateWeightPointPressures
		- calculatePressureMetrics
		- 标定文件保持业务附件原样
		- 坐垫先从 23×23 插值到 46×46 靠背先从 25×32 插值到 50×64
		- 输入为置零后的插值完整 ADC 矩阵
		- 调用层只按标定结果补齐同形 pressureMatrixKPa
	- 有效点
		- 由标定文件定义
		- 标准处理器不增加阈值 掩码或数量条件
	- 砝码段
		- 条件 有效点数小于等于三百
		- 标定输入
			- 座椅取降序第五至第七十位均值
			- 座椅不足五点时取全部
			- 靠背取降序前四十六位均值
		- 逐点分配
			- 标定输入经过基础曲线得到目标平均压强
			- 每点 ADC 经过同一基础曲线得到响应
			- 按响应比例分配逐点压强
			- 有效点平均压强保持为目标平均压强
			- 归一化后不再逐点截断
	- 真人段
		- 条件 有效点数大于三百
		- 每个有效点独立经过基础曲线
		- 每点结果乘真人系数二点二
		- 不计算整帧目标平均压强
		- 不执行比例归一化
	- 基础曲线
		- 座椅六段 PCHIP 局部三次
			- 低端按过原点斜率
			- 高端基础压强封顶十八点五千帕
		- 靠背七段线性
			- 低端沿第一段外推并限制非负
			- 高端基础压强封顶十八点五千帕
	- 最大压强
		- 直接取最终逐点压强矩阵最大值
	- 传感面判定
		- 键含 back 用靠背系数
		- 键含 sit 或 seat 用坐垫系数
		- 未定义类型直接报错
		- 不再用原始 ADC 充当压强

- 压力换算
	- 公式
		- 压强乘单点面积乘零点一
		- 零点一为单位换算系数
	- 单点面积
		- endi 靠背 一点三
		- endi 坐垫 一
		- 汽车 Y 靠背 一点九
		- 汽车 Y 坐垫 二点二五
		- 其余 一
	- 注意
		- 前后端共用同一张表
		- 改动必须同步

- 精度约定
	- 逐点物理量保留一位小数
	- 标定矩阵必须与 ADC 等长
	- 标定矩阵出现非有限值时直接报错
	- 不在公式外修改压强正负或有效性
	- 前后端同一套取整规则
	- 副作用
		- 逐点先取整再求和
		- 存在累积误差
		- 导入时派生列偏低约千分之四

- 处理水印
	- 内容
		- 版本号 backend-zero-direct-v6-post-interpolation-calibration
		- ADC 预处理口径 zero-baseline-only
		- 阈值 高斯 相干的兼容请求值
		- 阈值与高斯均未应用
		- 高斯标准差为零
		- 无时序标记
		- 输出小数位
		- 公式文件与档位
	- 用途
		- 判断是否已算过
		- 版本与 ADC 预处理口径匹配
		- 且压强数组长度等于 ADC 长度
		- 且压力数组长度等于 ADC 长度
		- 满足则直接复用
		- 不满足优先按 calibrationAdcArr 重算
		- 没有时再使用 rawAdcArr

## 实现边界

- endi 四千帧线序缺参数
	- 现状
		- 两个函数调坐标表重映射时漏传源矩阵宽度
		- 该参数是取源值的必需项
		- 不传则索引算出非数字
		- 输出数组每项都是空值
	- 影响
		- 四千帧的 endi 走这条路径
		- 实测坐垫返回五百二十九个空值
		- 实测靠背返回八百个空值
		- 空值进处理器后被判非法归零
		- 表现为整片无数据而不报错
	- 对照
		- 一千帧走的函数传了参数
		- 工作正常
	- 待确认
		- 四千帧的源矩阵宽度是多少
		- 需实机验证后再修

- 旧广播分支不可达
	- 现状
		- 特定波特率下发送另一个字段名
		- 但该波特率变量初始值不同
		- 且连接流程从不改写它
	- 影响
		- 该分支实际不可达
		- 前端也没有对应处理函数

- 大矩阵二维尺寸不一致
	- 现状
		- 后端标准矩阵与三维均为六十四乘六十四
		- 二维组件对单矩阵系统固定三十二乘三十二
	- 影响
		- 二维视图与后端和三维不一致
		- 需补大矩阵专属尺寸分支

- 点数校验缺口
	- 现状
		- 点数表缺脚垫与大矩阵条目
	- 影响
		- 这两类在串口层直接放行
		- 尺寸异常要到在线判定才拦住
		- 坏帧统计里不计数

- 相干字段已死
	- 现状
		- 仍在配置与快照与接口与水印里传递
		- 但处理函数完全不读
	- 影响
		- 易误以为存在时序平滑

- 定时器互相覆盖
	- 现状
		- 三处都在设同一个定时器
		- 一千帧分支用固定八十毫秒
		- 四千帧分支用采样率倒数
		- 重建函数用带下限的采样率倒数
	- 影响
		- 同时接两类设备时谁最后设置谁生效
		- 设备断开也不会重建

- 前端公式镜像
	- 现状
		- 前端保留完整分段公式
		- 但实时链路不调用它换算
	- 影响
		- 只用其中的单位元数据与单点面积与汇总函数
		- 两处面积表需手工同步

- 派生列取整偏差
	- 现状
		- 导入时由压强派生压力会二次取整
	- 影响
		- 总和系统性偏低约千分之四

- 报告有效阈值标注未生效
	- 现状
		- 常量定义为五
		- 仅出现在指标卡与附录文字
		- 计算中一次未使用
		- 实际判定为大于零
	- 影响
		- 报告声称按五筛选
		- 实际只要大于零就计入
		- 波及有效点数
		- 波及有效面积
		- 波及重心权重

- 报告点间距对所有传感面写死
	- 现状
		- 报告内点间距固定十毫米
		- 实际点距各传感面不同
	- 影响
		- 波及所有毫米量
			- COP 坐标
			- 左右前后偏移
			- 轨迹长度
			- 摆动范围
			- 平均速度
	- 风险
		- 历史报告已用旧数值做对比
		- 改动会导致新旧不可比

- 报告框选面积口径不一
	- 现状
		- 总览的面积列每点按一平方厘米
		- 详细分析的有效面积按传感面真实点面积
	- 影响
		- 同一份报告两个面积列不可直接比较
		- 非一平方厘米的传感面总览面积偏小

- 报告风险等级混用两种量
	- 现状
		- 占比分支用压力总和
		- 七十的阈值判的是压强最大值
	- 影响
		- 压强与压力模式下同一区域可能给出不同等级
		- 七十这个数无标定依据

- 报告局部 COP 原点未随框移动
	- 现状
		- 框内重心用框内点算
		- 但毫米坐标仍以整块矩阵中心为原点
	- 影响
		- 数值实际是该框重心的绝对位置
		- 不是框内相对位置
		- 命名易被误解

- 报告稳定性评分无依据
	- 现状
		- 四个惩罚系数为经验值
		- 量纲不统一直接相加
		- 轨迹长度项权重最重
	- 影响
		- 采集越久分数越低
		- 不可跨时长比较
		- 不可跨设备比较

- 报告空帧重心处理不一致
	- 现状
		- 整段汇总只过滤非有限值
			- 空帧的原点会算进平均
		- 框选段过滤了无有效点的帧
	- 影响
		- 全矩阵重心被空帧往中心拉
		- 框选段跨空档连线
		- 轨迹长度偏大

- 报告其余传感面段少两行
	- 现状
		- 主传感面框选表八行
		- 其余传感面框选表六行
		- 缺 ADC 总和与风险等级
	- 影响
		- 多传感面记录里信息量不对等
