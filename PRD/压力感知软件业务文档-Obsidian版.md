# 压力感知软件业务定义与功能实现

## 业务定义
- 产品
	- 定义
		- 一套压力传感器桌面软件
		- 用于连接压力采集设备
		- 用于展示实时压力分布
		- 用于保存实验或演示数据
		- 用于回放、对比、导出和生成报告
	- 业务本质
		- 把硬件输出的压力信号转成可观察、可复核、可交付的数据
	- 使用边界
		- 用于研发、测试、演示、交付和辅助评估
		- 不作为医疗诊断系统
		- 不自动给出人体健康结论

- 设备
	- 定义
		- 通过 USB 串口连接到电脑的压力传感器硬件
		- 设备持续输出压力数据帧
	- 业务属性
		- MAC 地址
		- 设备类型
		- 设备类别
		- 设备别名
		- 连接状态
		- 授权状态
	- 业务规则
		- 设备必须能被识别
		- 设备必须匹配当前系统类型
		- 设备必须通过本地配置或授权校验
		- 设备异常时不能继续作为可信数据来源

- MAC 地址
	- 定义
		- 设备的唯一识别码
		- 用于区分不同硬件
	- 业务作用
		- 绑定设备类型
		- 判断设备是否已配置
		- 追踪采集数据来源
		- 辅助现场排障
	- 业务规则
		- MAC 不能为空
		- MAC 格式必须合法
		- 一个 MAC 应对应一个明确设备类型

- 设备类型
	- 定义
		- 软件对设备数据含义的分类
		- 决定设备输出的数据应该被当作哪种压力面处理
	- 类型示例
		- 靠背设备
		- 坐垫设备
		- 床垫设备
		- 手套设备
		- 脚垫设备
		- 大矩阵设备
	- 业务作用
		- 决定矩阵尺寸
		- 决定显示对象
		- 决定统计口径
		- 决定是否可以与其他数据对比

- 传感器系统
	- 定义
		- 软件中的业务场景配置
		- 用来区分当前连接和展示的是哪类压力系统
	- 系统示例
		- 汽车座椅
		- 汽车座椅 Y
		- Endi 座椅
		- 床垫
		- 手套
		- 脚垫
		- 大矩阵
	- 业务作用
		- 约束可连接设备
		- 确定默认展示方式
		- 确定矩阵规格
		- 确定导出字段
		- 确定报告含义

- 传感面
	- 定义
		- 一个可独立展示、分析、导出和报告的压力采集面
	- 类型
		- 靠背
		- 坐垫
		- 床垫
		- 手部
		- 脚部
		- 大矩阵面
	- 业务规则
		- 座椅类系统可以同时包含靠背和坐垫
		- 靠背和坐垫可独立显示
		- 靠背和坐垫可独立设置方向
		- 单矩阵系统通常只有一个主传感面

- 压力帧
	- 定义
		- 某一时刻设备输出的一组压力数据
		- 是实时展示和历史回放的最小时间单位
	- 业务内容
		- 时间
		- 设备来源
		- 传感面
		- 点位数据
		- 采样频率
		- 数据质量
	- 业务规则
		- 一帧必须能还原为明确矩阵
		- 异常帧不能作为可信统计来源
		- 历史回放按帧推进
		- 数据对比按帧或时间点对齐

- 压力矩阵
	- 定义
		- 将压力帧中的点位按行列组织后的二维数据
	- 业务属性
		- 宽度
		- 高度
		- 点数
		- 传感面
		- 方向
		- 压力值
	- 业务作用
		- 用于 2D 展示
		- 用于 3D 展示
		- 用于指标计算
		- 用于框选分析
		- 用于历史保存
		- 用于导出和报告
	- 业务规则
		- 点数必须等于宽度乘高度
		- 同类数据对比时矩阵规格必须一致
		- 矩阵方向必须可追溯

- 实时数据
	- 定义
		- 设备在线时持续进入软件的数据
	- 业务作用
		- 驱动实时视图
		- 驱动实时图表
		- 作为采集保存的数据来源
	- 业务规则
		- 实时数据不自动成为历史
		- 只有用户开始采集后才会保存
		- 设备断开后实时数据应停止更新

- 采集任务
	- 定义
		- 用户主动保存一段实时压力数据的业务动作
	- 业务属性
		- 采集名称
		- 备注
		- 开始时间
		- 结束时间
		- 帧数据
		- 设备信息
		- 方向状态
		- 置零状态
	- 业务规则
		- 采集前必须有有效设备
		- 采集中保存全量矩阵
		- 框选不限制采集范围
		- 采集中不允许修改方向
		- 停止采集后生成历史记录

- 历史记录
	- 定义
		- 一次采集完成后保存下来的数据记录
	- 业务用途
		- 回放
		- 对比
		- 导出
		- 生成报告
		- 备注归档
	- 业务属性
		- 记录名称
		- 记录时间
		- 帧数量
		- 备注
		- 框选信息
		- 设备来源
	- 生命周期
		- 创建
		- 查看
		- 回放
		- 重命名
		- 备注
		- 导出
		- 删除

- 回放
	- 定义
		- 将历史记录按时间顺序重新播放
	- 业务用途
		- 复盘采集过程
		- 查找关键帧
		- 复核压力变化
		- 为报告和对比做准备
	- 业务控制
		- 播放
		- 暂停
		- 拖动进度
		- 倍速播放
		- 退出回放
	- 业务规则
		- 回放不改变历史原始数据
		- 回放时展示历史帧而不是实时帧
		- 退出回放后应回到实时状态

- 框选区域
	- 定义
		- 用户在传感面上圈定的局部分析区域
	- 业务用途
		- 查看局部压力
		- 比较不同区域
		- 生成区域曲线
		- 进入报告和导出
	- 业务属性
		- 所属传感面
		- 起点坐标
		- 区域宽度
		- 区域高度
		- 区域名称
		- 区域颜色
	- 业务规则
		- 框选只影响分析
		- 框选不影响采集范围
		- 框选不裁剪历史数据
		- 框选必须在有效传感区域内

- 框选模板
	- 定义
		- 可复用的框选区域配置
	- 业务用途
		- 固定分析区域
		- 保持多次测试口径一致
		- 提升现场分析效率
	- 保存内容
		- 区域坐标
		- 所属传感面
		- 区域名称
		- 区域颜色
	- 不保存内容
		- 压力数据
		- 历史帧
		- 采集任务

- 量尺
	- 定义
		- 用于测量传感面两点距离的辅助工具
	- 业务用途
		- 辅助描述接触范围
		- 辅助解释受力区域大小
	- 业务规则
		- 不影响采集
		- 不影响统计
		- 不影响导出
		- 只作为观察辅助

- 方向修正
	- 定义
		- 对传感面数据方向做业务校正
	- 操作
		- 左右翻转
		- 上下翻转
		- 90 度旋转
	- 业务用途
		- 让屏幕方向符合真实设备摆放
		- 让回放、导出、报告空间口径一致
	- 业务规则
		- 靠背和坐垫方向独立
		- 方向修正需要保存
		- 采集中不允许改变方向

- 预压力置零
	- 定义
		- 将当前压力状态作为基线扣除
	- 业务用途
		- 去掉设备初始偏置
		- 去掉空载或预压背景
		- 突出后续压力变化
	- 业务影响
		- 影响实时展示
		- 影响统计指标
		- 影响采集数据
		- 影响导出和报告
	- 业务规则
		- 必须记录是否置零
		- 必须记录置零时间
		- 必须保留置零基线

- 可视化参数
	- 定义
		- 控制压力图展示效果的参数
	- 参数
		- 图像平滑
		- 颜色调整
		- 自动颜色
		- 噪点过滤
		- 高度调整
		- 响应速度
	- 业务用途
		- 改善现场观察效果
		- 适配不同设备量程
		- 适配不同演示环境
	- 业务边界
		- 可视化参数不能破坏数据可追溯
		- 用户应能理解调整后的展示含义

- 压强公式
	- 定义
		- 将传感器数值转换成压力指标的计算口径
	- 业务用途
		- 计算平均压力
		- 计算最大压力
		- 计算压力总和
		- 生成报告指标
		- 生成导出字段
	- 业务规则
		- 实时展示、导出、报告应使用同一公式口径
		- 公式变更应能被配置和追踪

- 数据质量
	- 定义
		- 对设备输出数据稳定性和可信度的判断
	- 质量问题
		- 坏帧
		- 连续坏帧
		- 点数不匹配
		- 采样率异常
		- 设备离线
	- 业务作用
		- 提醒用户检查设备
		- 阻止异常数据误用
		- 辅助现场排障

- 导入数据
	- 定义
		- 从外部文件加载进软件的数据
	- 来源
		- CSV
		- XLSX
		- 旧版本兼容文件
	- 业务用途
		- 回放
		- 对比
		- 报告
		- 二次分析
	- 业务规则
		- 文件必须可解析
		- 字段必须可识别
		- 矩阵点数必须合法
		- 导入数据应保留来源标识

- 导出数据
	- 定义
		- 将历史数据或对比结果输出为外部文件
	- 格式
		- CSV
		- XLSX
	- 业务用途
		- 客户交付
		- 科研分析
		- 内部复核
		- 算法处理
	- 业务要求
		- 可打开
		- 可解释
		- 可复核
		- 可再次导入

- 数据对比
	- 定义
		- 比较两组可比压力数据的差异
	- 对比对象
		- 基准数据 A
		- 对比数据 B
		- 差值数据
	- 对比模式
		- 两条历史记录对比
		- 同一记录两个时间点对比
		- 历史数据与导入数据对比
		- 两条导入数据对比
	- 业务规则
		- A 是基准
		- B 是对照
		- 差值为 B 减 A
		- 矩阵规格不一致不能对比
		- 数据为空不能对比

- 报告
	- 定义
		- 将一条记录整理成可阅读和可交付的分析文档
	- 当前报告
		- COP PDF 报告
	- 业务内容
		- 数据概览
		- 平均压力图
		- 压力趋势
		- COP 轨迹
		- 统计指标
		- 框选区域分析
	- 业务边界
		- 报告描述数据现象
		- 报告不自动判断方案优劣
		- 报告不输出医疗诊断

- COP
	- 定义
		- 压力中心轨迹
		- 表示压力重心随时间变化
	- 业务用途
		- 观察重心偏移
		- 观察受力稳定性
		- 观察姿态变化
	- 业务边界
		- COP 是辅助指标
		- 需要结合场景解释
		- 不能单独代表舒适性结论

- 核心指标
	- 平均压力
		- 表示有效受力区域的平均压力水平
	- 最大压力
		- 表示当前区域最高压力点
	- 压力总和
		- 表示整体受力强度
	- 有效点数
		- 表示参与统计的有效压力点数量
	- 受压面积
		- 表示有效点换算后的接触面积
	- 压力中心
		- 表示当前压力分布的重心位置
	- 差值
		- 表示 B 相对 A 的绝对变化
	- 变化率
		- 表示 B 相对 A 的比例变化

## 功能如何实现
- 首次配置
	- 用户目标
		- 让软件知道当前有哪些合法设备
		- 让设备 MAC 与设备类型建立关系
	- 实现方式
		- 用户首次进入软件时先检查本地是否存在设备配置
		- 如果没有配置，进入 MAC 配置页面
		- 用户输入设备 MAC 和设备类型
		- 系统校验 MAC 格式和设备类型
		- 校验通过后保存到本地设备缓存
		- 后续启动直接读取本地缓存
	- 结果
		- 软件知道哪些设备可以使用
		- 设备连接后可以自动匹配业务类型

- 一键连接
	- 用户目标
		- 不手动选择串口
		- 快速连接压力设备
	- 实现方式
		- 用户点击连接
		- 系统扫描电脑串口
		- 系统筛选疑似传感器设备
		- 系统自动探测通信速率
		- 系统建立稳定串口连接
		- 系统读取设备 MAC
		- 系统根据 MAC 匹配设备类型
		- 系统校验设备是否允许使用
		- 系统开始监听设备数据
	- 结果
		- 设备状态变为已连接
		- 实时数据开始进入软件
		- 用户可以查看实时压力图

- 重新连接
	- 用户目标
		- 设备断开或异常后恢复连接
	- 实现方式
		- 用户点击重新连接
		- 系统先清理已断开的串口
		- 系统再判断是否存在长时间无数据的僵尸设备
		- 系统保留仍然正常工作的连接
		- 系统重新扫描并补充连接
	- 结果
		- 无效连接被清理
		- 可用设备重新进入实时状态

- 实时展示
	- 用户目标
		- 看到设备当前压力分布
		- 看到压力变化趋势
	- 实现方式
		- 设备持续发送压力帧
		- 系统校验每帧是否完整
		- 系统把点位数据转换成压力矩阵
		- 系统按设备类型区分靠背、坐垫或其他传感面
		- 系统应用当前方向配置
		- 系统将数据推送到主界面
		- 前端根据当前视图渲染 2D 或 3D
		- 前端同步更新压力曲线和压力中心
	- 结果
		- 用户实时看到压力变化
		- 用户能切换不同传感面和视图

- 2D 展示
	- 用户目标
		- 以平面方式查看每个压力点
	- 实现方式
		- 系统将压力矩阵映射到二维网格
		- 每个格子代表一个传感点
		- 数值大小映射为颜色或高度
		- 用户可缩放、拖动、重置视图
	- 结果
		- 用户能精确观察点位压力

- 3D 展示
	- 用户目标
		- 以更直观的立体方式查看压力分布
	- 实现方式
		- 系统将压力矩阵映射成三维点或模型表面
		- 压力越大，点位高度或颜色变化越明显
		- 座椅类系统可展示靠背和坐垫
		- 用户可切换整体、靠背、坐垫视角
	- 结果
		- 用户能直观看到受力集中和分布形态

- 可视化调节
	- 用户目标
		- 让压力图更适合当前设备和场景
	- 实现方式
		- 用户调整平滑、颜色、噪点、高度、响应速度等参数
		- 系统只重新计算展示效果
		- 系统保留原始数据和业务数据
		- 参数可按系统保存为默认值
	- 结果
		- 现场展示更清晰
		- 不同设备可使用不同显示口径

- 方向修正
	- 用户目标
		- 让屏幕方向与真实设备摆放一致
	- 实现方式
		- 用户执行左右翻转、上下翻转或旋转
		- 系统记录当前传感面的方向配置
		- 靠背和坐垫分别保存方向
		- 实时展示按方向修正
		- 采集保存时也记录方向
		- 回放和导出按相同方向解释数据
	- 结果
		- 实时、历史、导出、报告空间口径一致

- 预压力置零
	- 用户目标
		- 去掉初始背景压力
		- 只观察后续压力变化
	- 实现方式
		- 用户点击置零
		- 系统读取当前矩阵作为基线
		- 后续每帧用当前值减去基线值
		- 小于零的结果按零处理
		- 系统记录置零时间和基线状态
	- 结果
		- 视图和统计从新的压力基线开始
		- 后续导出和报告可追溯置零状态

- 框选分析
	- 用户目标
		- 分析局部区域压力
		- 比较不同区域受力
	- 实现方式
		- 用户在 2D 视图中拖出矩形区域
		- 系统把屏幕区域换算成矩阵坐标
		- 系统保存区域所属传感面和坐标
		- 实时模式下直接计算当前区域指标
		- 回放模式下按历史帧计算区域曲线
		- 导出和报告可带上框选区域结果
	- 结果
		- 用户能查看局部平均压力、最大压力、压力总和、面积和压力中心

- 框选模板
	- 用户目标
		- 复用常用分析区域
	- 实现方式
		- 用户把当前框选保存为模板
		- 系统只保存区域坐标和名称
		- 用户下次选择模板后系统恢复相同框选
		- 模板按传感面判断是否适用
	- 结果
		- 多次测试可以保持一致分析区域

- 量尺
	- 用户目标
		- 估算传感面上两点距离
	- 实现方式
		- 用户在 2D 视图中放置测量线
		- 系统记录起点和终点
		- 系统根据设备点距换算实际距离
		- 量尺仅用于观察，不写入采集数据
	- 结果
		- 用户能辅助判断受力区域尺寸

- 数据采集
	- 用户目标
		- 保存一段可回放、可导出、可报告的数据
	- 实现方式
		- 用户点击开始采集
		- 系统要求填写采集名称和备注
		- 系统确认设备在线且类型合法
		- 系统开始持续保存每一帧业务矩阵
		- 系统保存方向、置零、设备来源等元数据
		- 用户点击停止采集
		- 系统结束写入并生成历史记录
	- 结果
		- 采集过程成为一条历史记录
		- 后续可回放、导出、对比和报告

- 历史列表
	- 用户目标
		- 管理已采集的数据
	- 实现方式
		- 系统按采集记录生成历史列表
		- 用户可搜索、选择、重命名、备注、删除
		- 用户可从历史列表进入回放、导出、对比和报告
	- 结果
		- 历史数据形成可管理的数据资产

- 历史回放
	- 用户目标
		- 复盘某次采集过程
	- 实现方式
		- 用户选择历史记录
		- 系统加载该记录的所有帧
		- 系统按帧顺序推送到展示界面
		- 用户可播放、暂停、拖动进度、切换倍速
		- 系统遇到异常帧时跳过或提示
		- 用户退出后恢复实时模式
	- 结果
		- 历史数据像实时数据一样重新展示

- CSV/XLSX 导入
	- 用户目标
		- 使用外部文件继续分析
	- 实现方式
		- 用户选择文件上传
		- 系统校验文件类型
		- 系统校验字段结构
		- 系统校验矩阵点数和数值合法性
		- 校验成功后转为可回放数据
		- 校验失败时拒绝导入
	- 结果
		- 导入数据可参与回放、对比和报告

- CSV/XLSX 导出
	- 用户目标
		- 把历史数据交付给客户或用于二次分析
	- 实现方式
		- 用户选择历史记录
		- 用户选择导出字段
		- 用户选择保存路径
		- 系统读取历史帧和元数据
		- 系统展开矩阵字段和指标字段
		- 系统生成 CSV 或 XLSX 文件
		- 系统返回文件位置
	- 结果
		- 用户获得可打开、可分析、可再次导入的数据文件

- 数据对比
	- 用户目标
		- 比较两组压力数据差异
	- 实现方式
		- 用户选择基准数据 A
		- 用户选择对比数据 B
		- 系统校验两组数据是否可比
		- 系统按帧或时间点对齐
		- 系统分别展示 A、B 和差值
		- 系统计算指标差异和变化率
		- 用户可导出当前对比结果
	- 结果
		- 用户能看到两组方案、姿态或时间点之间的压力变化

- COP 报告
	- 用户目标
		- 生成可交付的压力分析报告
	- 实现方式
		- 用户选择一条历史记录
		- 系统读取记录中的所有帧
		- 系统计算平均压力图
		- 系统计算压力总和趋势
		- 系统计算 COP 轨迹
		- 系统汇总统计指标
		- 系统叠加框选区域分析
		- 用户导出 PDF
	- 结果
		- 用户得到一份包含图表、指标和区域分析的 PDF 报告

- 系统配置
	- 用户目标
		- 调整软件默认系统和参数
	- 实现方式
		- 用户进入系统配置页面
		- 用户选择默认系统
		- 用户配置可选系统
		- 用户调整各系统可视化参数
		- 用户配置压强公式和靠背乘数
		- 系统保存配置
		- 后续启动或切换系统时读取配置
	- 结果
		- 软件可适配不同设备和交付场景

- 设备管理
	- 用户目标
		- 管理本机可用设备
	- 实现方式
		- 用户读取或录入设备 MAC
		- 用户选择设备类型和备注
		- 系统保存到本地缓存
		- 用户可修改或删除设备配置
	- 结果
		- 设备接入更稳定
		- 现场人员更容易识别设备

- 数据质量提示
	- 用户目标
		- 知道当前数据是否可信
	- 实现方式
		- 系统持续统计坏帧、连续坏帧和采样异常
		- 当异常超过阈值时更新设备状态
		- 前端提示用户检查设备或重新连接
	- 结果
		- 用户能及时发现设备或连接问题
