## New Features

- **数据对比新版页面**：数据对比页新增 A 基础数据、B-A 差值图、B 对比数据三张热力数字图，让用户可以直接看出两组压力数据的差异位置和差异强度。

- **同记录时间点对比**：支持在同一条历史记录中选择两个不同时间点进行 A/B 对比，适合观察同一次测试过程中的压力变化。

- **对比热力图放大查看**：每张对比热力图右上角增加放大入口，用户可以打开更清晰的大图，便于检查单个格子的压力值和差值。

- **对比播放栏整体放大**：对比页播放栏的放大功能升级为同时放大三张热力数字图和进度条，不再只放大控制条。

- **5x5 鼠标放大镜矩阵**：数据对比热力图支持鼠标悬停查看 5x5 局部矩阵，方便用户检查局部区域的压力值。

- **框选模板**：框选支持保存、应用、重命名和持久化。模板保存区域、设备类型、矩阵尺寸和显示对象，不保存压力数据。

- **CSV 单文件导出和导入校验**：同一条记录导出为一个 CSV 文件，并在导入时校验数据结构。结构错误时提示“数据有误”，避免错误数据进入历史列表。

- **endi 靠背 1024 线序映射**：靠背原始长度按 1024 处理，并根据实际线序生成靠背物理矩阵，再通过线性插值形成显示矩阵。

- **可视化调节 Max 设置**：图像润滑、颜色调节、噪点消除和高度调节的最大值可配置，并支持本地持久化。

- **MAC/Unique ID 配置强校验**：系统配置新增统一校验能力，保存前检查 MAC、Unique ID、设备类型和重复配置，减少设备映射错误。

- **批量设备配置保存**：后端支持批量保存设备配置，先整体验证再写入缓存，避免逐条保存导致部分成功、部分失败。

- **预压力置零采集口径**：置零从前端显示状态升级为后端采集口径，采集入库前扣减基线，并在导出时记录置零状态。

- **功能完成度跟踪文档**：新增 `noCompleted.md` 按分类维护功能完成度，未完成项置顶，便于后续 PRD 对齐和持续更新。

## Improvements

- **框选与采集解耦**：实时框选只影响显示和统计，不影响采集范围。采集始终保存全量矩阵，避免历史数据被框选范围污染。

- **回放框选一致性优化**：回放时如果存在框选，正常播放和拖动进度条都按框选范围刷新 2D/3D 视图和左侧图表。

- **左侧图表口径统一**：有框选时，压力曲线和面积曲线只展示框选数据，不再混入座椅或靠背整体数据。

- **数据对比页面信息降噪**：进入对比模式后隐藏无关数据和普通分析图表，只保留对比需要的热力图、曲线、汇总表和配置面板。

- **对比页视觉风格统一**：对比页面复用主页一级 header，使用主页一致的黑底、深灰边框和 `#0072EF` 蓝色交互色，去掉廉价荧光效果。

- **对比曲线可读性提升**：压力变化曲线和面积变化曲线补充横纵坐标、单位、图例和曲线说明，减少曲线重合时的理解成本。

- **数据汇总表增强**：汇总表补充 A、B、B-A、变化率列。差值和变化率用颜色及上下箭头表达变化方向。

- **2D 和 3D 颜色调节统一**：2D 数字和 3D 点图共用同一个颜色调节 value，减少同一数据在不同视图中表现不一致的问题。

- **2D 数字可读性优化**：2D 数字保持整数显示，文字使用白色且不加黑色描边。颜色透明度只作用于背景，不影响文字透明度。

- **3D 点图色值优化**：3D 点图颜色加深并增强红色高值表现，减少整体发灰、像有蒙层的问题。

- **视图缩放稳定性优化**：放大和缩小每次固定 10%，避免多次点击出现 10%、20%、25% 不一致的问题。

- **视角切换顺序统一**：靠背和坐垫的视角切换都按 0°、向里 45°、向里 90°循环。

- **3D 旋转中心优化**：单独显示靠背或座椅时，左键旋转中心对齐当前对象；整体显示时，旋转中心对齐整体对象。

- **画布翻转数据持久化**：翻转不再只是前端显示变化，而是改变业务数据源并持久化，让采集、回放和导出保持一致。

- **靠背有效区域显示优化**：靠背补 0 区域不再展示点，真实有效区域内的 0 值仍保留显示。

- **历史数据切换稳定性优化**：本地数据、导入数据、导出数据之间频繁切换时，不再复制列表项，也会清理残留选中态。

- **历史列表性能优化**：历史数据抽屉支持分批渲染，减少大量历史记录时的卡顿。

- **打开路径体验优化**：历史数据点击“打开”支持打开文件夹，失败时提示原因。

- **打包后缓存路径优化**：serial cache 写入可写目录，不再写入 `resources/app.asar`，避免打包后出现 ENOENT。

- **异常帧处理更稳**：实时数据和回放数据会校验空帧、矩阵缺失、长度不匹配和非法数值，避免异常帧污染历史数据或导致软件崩溃。

- **数据质量信息补充**：实时数据中补充采样率、帧间隔、矩阵元信息和数据质量状态，方便前端判断能否展示或采集。

- **回放倍速规则统一**：回放倍速限制为 `0.5x/1x/2x/4x`，非法倍速自动回退到 `1x`。

- **CSV metadata 更完整**：导出文件补充软件版本、设备 MAC、设备类型、帧索引、时间戳、压力单位、噪点状态、方向和置零状态，便于追溯。

- **carY 换算说明补充**：carY 导出增加 `pressure_conversion=carY_100_div_3` 和说明字段，避免后续分析时误解压力口径。

- **框选快捷键输入态保护**：编辑模板名、区域名或手动坐标时，Delete、Backspace 和方向键只作用于输入框，不会误删或移动框选区域。

- **框选模板兼容和归并**：模板读取兼容旧版 key 和旧字段结构，并归并到稳定存储 key，减少刷新后模板丢失或重复的问题。

- **框选面板交互优化**：框选面板重排为更紧凑的小浮窗，支持清除全部、查看、删除、重命名模板，并避免内部滚动条遮挡操作。

- **框选重心计算优化**：框选重心先在局部区域计算，再投影回整张矩阵坐标，压力中心图可以显示多个框选区域的真实重心。

- **历史回放与框选状态解耦**：打开历史抽屉或选择历史记录不会自动关闭框选工具，框选状态由框选工具自身控制。

- **对比页模板和曲线稳定性优化**：数据对比页曲线线条收敛到更克制的宽度，框选模板读取顺序稳定，避免重启后模板显示错乱。

## Bug Fixes

- Fixed **本地编辑模式切换到导入数据后编辑态残留** 的问题，切换页签时应清理编辑、删除、下载等选中状态。

- Fixed **历史数据频繁切换后界面数据重复追加** 的问题，列表数据需要按当前来源重新生成。

- Fixed **导入 CSV 后点击播放 message error** 的问题，导入成功的数据必须满足软件结构并可播放。

- Fixed **回放拖动进度条后显示全量原始数据** 的问题，拖动进度条也必须使用当前框选数据。

- Fixed **画布翻转后采集仍保存翻转前数据** 的问题，采集应保存翻转后的业务矩阵。

- Fixed **退出数据对比或回放后设备仍连接但显示未连接** 的问题，退出后应恢复真实连接状态。

- Fixed **2D 数字超出单位格子和字体异常** 的问题，2D 数字应保持原有字体大小和整数显示。

- Fixed **可视化调节切换页面后丢失** 的问题，调节值和 Max 值都需要本地持久化。

- Fixed **靠背插值方式不一致** 的问题，靠背显示矩阵需要与坐垫一样使用线性插值。

- Fixed **3D 点图和 2D 数字补 0 区域方向不一致** 的问题，二者必须共用同一套有效 mask。

- Fixed **四个框选导致统计区域撑大、图表不自适应** 的问题，多框选统计区需要保持布局稳定。

- Fixed **回放曲线依赖实时帧导致不显示** 的问题，回放模式优先使用历史接口返回的压力和面积曲线。

- Fixed **框选后保存模板仍提示需要先创建框选区域** 的问题，保存时直接读取当前真实框选区域。

- Fixed **保存模板后退出仍提示保存模板** 的问题，保存成功后当前框选会被标记为已保存模板。

- Fixed **应用已有模板后退出仍提示保存模板** 的问题，已来自模板的框选可以直接退出。

- Fixed **重新进入框选后上一次框选信息仍残留** 的问题，退出工具时同步清空 DOM、内部区域和面板状态。

- Fixed **启动框选会暂停回放** 的问题，回放中可以继续播放并同时画框选。

- Fixed **启动框选会自动关闭历史抽屉** 的问题，框选和历史抽屉不再互相抢状态。

- Fixed **实时状态下点击框选后底部仍显示历史播放控件** 的问题，播放条只在真正回放且非对比页时显示。

- Fixed **对比页退出后框选区域残留到普通页面** 的问题，退出对比时清理全局框选实例和选区状态。

- Fixed **对比页结论文案字段缺失导致崩溃** 的问题，缺失字段不再阻断页面展示。

- Fixed **座椅/靠背 3D 视图第一次点击放大反向缩小** 的问题，切换单独模式后重置缩放基准。

- Fixed **翻转再次操作基于旧缓存方向计算** 的问题，新的方向从当前帧实际方向派生，避免二次翻转错位。

## Breaking Changes

- **CSV 导出格式变更**：同一条历史记录不再拆分为坐垫和靠背两个文件，而是导出为一个 CSV 文件。后续导入、回放和对比都以该单文件结构为准。

- **翻转规则变更**：画布翻转会改变业务数据源并持久化，不再只是视觉层翻转。用户需要确认翻转方向后再开始采集。

- **数据导入规则变更**：导入数据必须满足软件认可的数据结构。结构错误的数据不会进入列表，也不能播放。

- **框选数据边界变更**：框选不再作为采集范围。它只影响显示、统计、图表和对比范围。

- **置零数据口径变更**：置零会影响后端采集入库和 CSV 导出，不再只是前端显示效果。测试时需要记录是否启用了置零。

- **方向数据结构变更**：方向状态从简单 `left/up` 扩展为支持 `byKey`、`rotateDegree` 和 `data_direction`，坐垫和靠背可以分别保存方向。

## Deprecations

- **不再使用右侧抽屉作为框选主入口**：框选回到顶部工具栏小浮窗，避免遮挡数字矩阵和右侧图表。

- **去掉“响应速度”调节项**：可视化调节保留图像润滑、颜色调节、噪点消除和高度调节。

- **不做 3D 数字视图**：当前版本只保留 2D 数字矩阵、3D 点图和 3D 模型。

## Action Required

- **测试需要覆盖真实设备**：一键连接、重连、断开、采集 30 分钟、退出回放状态恢复、打包缓存路径都需要真实设备验证。

- **需要确认压力单位**：界面当前显示 kPa，但是否需要统一换算为标准 kPa 仍需业务确认。

- **需要确认 CSV legacy 兼容范围**：如果历史 CSV 格式较多，需要补充字段别名和缺省策略。

- **需要确认 endi 靠背线序最终版本**：如果硬件线序再次变化，需要同步更新矩阵转换和有效 mask。

## Not Included

- PDF/Word 自动报告。

- 云端账号、权限和多用户。

- 算法级姿态评估或 AI 分析。

- 3D 数字视图。
