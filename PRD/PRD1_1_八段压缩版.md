## 1. Summary

PRD1.1 是对压力感知软件原 PRD 的增量补充，重点解决真实设备连接、数据接收、显示视图、功能工具、数据可视化、采集回放、CSV 导入导出和数据对比中的一致性问题。

本版本的核心目标是让数据链路更可信，让框选、翻转、置零、回放、导出和对比之间不互相污染。用户可以稳定连接设备，采集全量数据，回放时按框选查看，导出单个 CSV 文件，并在新版数据对比页面中查看 A/B/B-A 差异。

## 3. Background

JQ Tools 是一个本地压力感知桌面软件，连接坐垫和靠背传感器后，实时展示 2D 数字矩阵、3D 点图、3D 模型、压力曲线、面积曲线，并支持采集、历史回放、CSV 导入导出、框选区域分析和数据对比。

近期开发中新增和修复了大量功能，包括 MAC/Unique ID 强校验、批量设备配置保存、数据质量信息、endi 靠背 1024 线序、框选模板、回放框选、置零采集口径、方向持久化、CSV 单文件导出、CSV 导入校验、数据对比新版 UI、5x5 放大镜和播放栏整体放大。

原 PRD 已覆盖主要模块，但新增功能分散在专项 PRD、架构更新日志和实现记录中。PRD1.1 的作用是把这些变更合并成可执行、可验收、可交付的需求口径。

## 5. Market Segments

| 用户 | 使用场景 | 需要解决的问题 |
|---|---|---|
| 设备调试人员 | 连接坐垫和靠背传感器，检查数据是否稳定 | 快速定位串口、MAC、设备类型和异常帧 |
| 采集操作人员 | 完成一次压力测试并保存历史数据 | 操作简单，采集全量数据，误操作少 |
| 数据分析人员 | 查看回放、框选区域、压力曲线和面积曲线 | 图表、2D、3D 口径一致 |
| 对比分析人员 | 对比两次记录或同一记录两个时间点 | 快速看到 A/B 差异、局部差异和变化率 |
| 验收人员 | 检查版本是否可交付 | 需要清晰功能清单、验收标准和风险项 |

| 约束 | 说明 |

| 数据结构固定 | 历史数据、CSV、回放和对比必须使用软件认可的数据结构 |

## 6. Value Propositions

| 价值 | 用户收益 |
|---|---|
| 连接更省心 | 一键连接自动识别设备，失败时能看到原因 |
| 数据更可信 | 采集保存全量数据，框选只影响显示和统计 |
| 分析更清楚 | 框选后图表、2D、3D 只展示目标区域数据 |
| 对比更直观 | A、B、B-A 三张热力数字图和曲线同时展示 |
| 结果可复用 | 导出的 CSV 可再次导入、回放和参与对比 |
| 异常更可控 | 坏帧、坏 CSV、非法倍速都有明确处理 |

主要痛点和解决方式：

| 痛点 | PRD1.1 解决方式 |
|---|---|
| 导入错误 CSV 后播放报错 | 导入前做结构校验，失败提示“数据有误” |
| 框选影响采集范围 | 采集始终保存全量矩阵 |
| 回放拖动进度后变回全量数据 | 回放数据源和图表都读取当前框选范围 |
| 2D/3D 颜色参数不一致 | 共用颜色调节 value，但允许不同显示色阶 |
| 靠背补 0 点显示错误 | 2D、3D、原始数据、对比页共用有效 mask |
| 历史列表大量数据卡顿 | 历史抽屉分批渲染 |

## 7. Solution

### 7.1 UX / Prototypes

| 区域 | PRD1.1 要求 |
|---|---|
| 主页 header | 对比页复用主页一级 header，隐藏普通二级工具栏 |
| 对比页视觉 | 黑底、深灰边框、`#0072EF` 蓝色交互，不使用廉价荧光 |
| 框选浮窗 | 回到顶部工具栏小浮窗，不遮挡数字矩阵和右侧图表 |
| 2D 数字 | 整数显示，白色文字，无黑色描边，背景透明不影响文字 |

| 热力图放大 | 对比页每张热力图右上角有放大 icon |
| 5x5 放大镜 | 鼠标悬停热力图时显示局部 5x5 矩阵 |
| 播放栏放大 | 点击后放大三张热力图和进度条，不只放大控制条 |

### 7.2 Key Features

#### 7.2.1 模块一：打开软件后的连接流程

| 功能 | 规则 |
|---|---|
| MAC 配置 | 系统配置页维护 MAC/Unique ID 与设备类型映射 |
| 强校验 | 校验格式、重复 MAC、重复 Unique ID、不支持设备类型 |
| 批量保存 | 先整体验证，再写入缓存，避免部分成功 |
| 一键连接 | 扫描串口、识别 CH340、探测波特率、读取 MAC、匹配设备类型 |
| 重连 | 重连前释放旧串口、parser、listener、timer 和缓存状态 |
| 缓存路径 | serial cache 写入可写目录，禁止写入 `app.asar` |

#### 7.2.2 模块二：设备数据接收与处理

| 功能 | 规则 |
|---|---|
| 帧校验 | 空帧、坏帧、长度不匹配、非法数值不得进入有效数据流 |
| 数据质量 | 实时数据附带采样率、帧间隔、矩阵元信息和质量状态 |
| 异常帧 | 回放可跳过损坏帧，连续异常达到阈值时停止并提示 |
| endi 靠背 | 1024 原始数据按 32x32 读取，映射到 25x32，再线性插值为 50x64 |
| 有效 mask | 顶部 9 行 11 列为有效窄区，其余补 0 点隐藏 |

#### 7.2.3 模块三：连接之后的展示视图

| 功能 | 规则 |
|---|---|
| 2D 数字 | 整数、白字、无黑描边、文字不透明 |
| 3D 点图 | 使用独立色阶，颜色更深，高值进入黄橙红 |
| 缩放 | 每次点击固定 10%，100% 到 110% 必须表现为放大 |
| 视角切换 | 靠背和坐垫按 0°、向里 45°、向里 90°循环 |
| 旋转中心 | 单对象围绕自身，整体视图围绕整体对象 |
| 动画稳定 | 切换对象和点图不能突然缩小、跳动或位移 |

#### 7.2.4 模块四：连接之后的功能工具模块

| 功能 | 规则 |
|---|---|
| 置零 | 前端同步基线到后端，采集入库前扣减，CSV 记录置零状态 |
| 框选 | 只影响显示、统计、图表和对比，不影响采集全量矩阵 |
| 框选模板 | 保存区域名称、坐标、颜色、设备 key、显示对象、矩阵尺寸 |
| 模板兼容 | 兼容旧 key 和旧字段，归并到稳定存储 key |
| 快捷键保护 | 输入框、弹窗、Popover 聚焦时不响应框选快捷键 |
| 翻转 | 坐垫支持上下、左右、90 度旋转；靠背支持左右翻转 |
| 方向持久化 | 支持 `byKey`、`rotateDegree`、`data_direction`，坐垫和靠背独立记录 |
| 可视化调节 | 润滑 0.1 步进，颜色最大 500，噪点最大 20，高度最大 10，去掉响应速度 |

#### 7.2.5 模块五：数据可视化和计算数据

| 功能 | 规则 |
|---|---|
| 压力指标 | 平均压力、最大压力、最小压力、压力总和 |
| 面积指标 | 有效点数和面积，按设备点距换算 |
| 框选图表 | 有框选时左侧图表只展示框选数据 |
| 多框选布局 | 最多 4 个框选，指标行自动分列，数字和单位不换行 |
| 框选重心 | 先算局部重心，再投影回整张矩阵坐标 |
| carY 说明 | CSV 增加 `pressure_conversion=carY_100_div_3` |

#### 7.2.6 模块六：采集、历史数据与回放

| 功能 | 规则 |
|---|---|
| 采集 | 始终采集全量矩阵，保存当前方向和置零后的业务矩阵 |
| 异常帧 | `device_error/matrix_error/offline` 不进入采集入库 |
| 历史列表 | 本地、导入、导出切换不重复追加，清理选中态 |
| 历史性能 | 历史抽屉分批渲染，滚动加载更多 |
| 回放倍速 | 只允许 0.5x、1x、2x、4x，非法倍速回退 1x |
| 回放损坏帧 | 空帧、矩阵缺失、长度错误、非法数值跳过 |
| 回放框选 | 播放和拖动进度条都按当前框选范围展示 |
| 退出回放 | 设备仍连接时恢复已连接状态 |

#### 7.2.7 模块七：数据导出与数据对比

CSV 导入导出：

| 功能 | 规则 |
|---|---|
| 单文件导出 | 同一条记录只导出一个 CSV，不拆坐垫/靠背两个文件 |
| 多矩阵区分 | 使用 `matrix_key/device_type` 区分坐垫和靠背 |
| metadata | 包含版本、MAC、设备类型、帧索引、时间戳、采样率、方向、置零、噪点状态 |
| 框选字段 | 有框选时导出 `selection_1_*` 等字段 |
| 导入校验 | 校验表头、矩阵列、统计列、矩阵长度和数值合法性 |
| 错误提示 | 结构错误提示“数据有误”，不进入列表 |
| legacy 兼容 | 兼容旧版 `xxx Data/Max/Aver/Area` 和新版 `realData` |

数据对比：

| 功能 | 规则 |
|---|---|
| 对比对象 | 坐垫对坐垫，靠背对靠背 |
| 跨记录对比 | 选择两条历史记录，按共同矩阵 key 对比 |
| 同记录时间点 | 同一记录内选 A/B 两个时间点，禁止同帧 |
| 三图展示 | A 基础数据、B-A 差值图、B 对比数据 |
| 热力数字图 | A/B 使用 2D 数字同款视觉，差值图使用红蓝语义 |
| 5x5 放大镜 | 鼠标悬停查看局部矩阵 |
| 播放栏放大 | 弹窗中三图和进度条同步刷新 |
| 曲线 | 跨记录显示 A/B/B-A，同记录显示单趋势线和 A/B 标记 |
| 汇总表 | 显示 A、B、B-A、变化率，并用颜色和箭头表达变化方向 |

### 7.3 Technology

| 技术点 | 要求 |
|---|---|

### 7.4 Assumptions

| 编号 | 假设 | 风险 |
|---|---|---|
| ASM-01 | 压力单位继续显示为 kPa | 如果硬件单位未确认，界面单位可能需要换算 |
