# 先看这里：恩迪坐垫 / 靠背压力算法 JS v2.12.0

本包按《假人传感衣对接调整文档》的要求整理，算法来自汽车座椅标定上位机 V2.7.110（恩迪坐垫 23×23、恩迪靠背 32×25）。对接文档 §1 要求的三件交付物如下：

| 对接文档要求 | 本包文件 |
| --- | --- |
| 1. 新版 JS 文件 | `算法JS/seatBackrestPressure_v2.12.0.js`（类型声明 `.d.ts`、构建记录 `.build.json`、接入说明、接入示例同目录） |
| 2. 标定原始数据表（§5.3 格式） | `原始数据与残差/`：75 份原始采集 CSV、`坐垫_砝码覆盖格原始表.csv`、`靠背_砝码覆盖格原始表.csv` 等 |
| 3. 方案选择、拟合方法、残差统计说明 | `交接文档/交接说明.md`（同内容 `.docx`） |

## 阅读顺序

1. `交接文档/交接说明.md`：方案（分部位曲线 + 位置级增益）、拟合方法（对数-对数幂律）、残差统计、书面确认、未完成项。
2. `交接文档/对接条款逐项核对.md`：对接文档整理为 44 条，逐条给出状态和证据（已完成 23、部分完成 9、需实测 5、按本项目对应 4、不适用 3）。
3. `算法JS/README_接口与接入.md`：接口、输入输出口径、旧版 v2.11.1 的迁移。
4. `原始数据与残差/数据口径与未测项目.md`：真值来源、§5.3 表各列含义、哪些数据还没测。
5. `复算与测试/README_复算.md`：如何逐字节复现 JS、如何与上位机逐帧对拍、如何复现数据表。

## 关键结论

- 平均压强和最大压强都从逐格 `kpa` 直接统计，`calculateDummyMatrixPressureMap` 的输出与上位机热力图格子、面板数字一致。
- 没有 150 点阈值、top50 分支、逐点 ×2；逐格压强不乘倍率，最大压强不做 ×2 / ÷3。
- 与上位机 V2.7.110 源码逐帧对拍：坐垫 6,200 帧、靠背 8,800 帧真实数据，以及 5 个超量程 / 真人合成场景，全部零差异。
- 还没完成、必须现场实测的：低压段 0.5–2.0 kPa、每个物理点 3 档单格标定（a、b）、硬币压头轮廓、均布加载、同批多台差异。记录表在 `交接文档/现场验收记录.xlsx`，`CELL_CALIBRATION` 在测完之前保持 null。
- 本 JS 只含恩迪坐垫和靠背，不含假人传感衣四个部位的算法。
