# 更换 Dummy 面积公式

安装后的面积公式位于软件安装目录的 `resources/kpa/`，独立于 `app.asar`。开发时对应 `server/kpa/`。

## 自动选择公式（默认）

`area_formula.json` 的默认内容：

```json
{
  "formulaFile": "auto"
}
```

把新公式 JS 文件放入该目录即可，例如 `dummyArea_v2.10.37.js`、`dummyArea_v3.0.js`。文件名只要求以 `dummyArea` 开头、以 `.js` 结尾。多个版本并存时优先选择文件名中数字版本最高的文件；无法从名称比较版本时按文件修改时间选择。

同名文件也可以直接覆盖。程序在后续数据计算时重新识别文件内容，不要求内部 `VERSION` 必须变化，不需要重启软件或重新打包。

## 指定公式

若需要固定版本或切回旧版，修改同目录的 `area_formula.json`：

```json
{
  "formulaFile": "dummyArea_v2.10.36.js"
}
```

填写文件名即可，不填写路径。文件名仍需以 `dummyArea` 开头、以 `.js` 结尾。以后文件改名时更新这里；设回 `auto` 可恢复自动选择。

## 公式接口

文件使用 CommonJS，保留与原交接文件兼容的导出：

```js
module.exports = {
  VERSION: '3.0.0',
  calculateDummyRawAreaFrame(rawMatrix, sensorType, physicalMask) {
    // 返回 null，或返回 { areaCm2, areaMatrixCm2 }。
    // areaMatrixCm2 是插值后、尚未旋转和居中的二维面积矩阵。
  },
};
```

原始矩阵尺寸和传感器类型保持原约定：上身 `27x12`、袖子 `2x18`、左右腿 `32x6`。面积单位为 `cm²`，面积矩阵尺寸为原始矩阵的两倍，仍使用原来 `1.5625 cm²` 的网格。

程序记录实际加载的文件名、版本及文件内容修订标识。替换后，后续实时数据及重新读取的历史、报告、对比、CSV 会使用当前公式；已打开的静态报告或历史曲线需要重新打开或重新请求。只有压强、缺少原始 ADC 的记录仍无法补算面积。

一次报告或导出固定使用开始计算时的公式，中途替换会在下一次请求时生效。复制过程中若文件暂时不完整，实时与回放会跳过失败帧并重试。

打包配置修改后需要先重新生成一次安装包。后续修改 `resources/kpa/` 下的公式和配置即可。软件升级或重新安装可能覆盖该目录，升级前保留自定义公式及配置。
